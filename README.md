### What I'm building
- **PersonalOS** — a local-first, multi-agent job-search assistant orchestrated with LangGraph: a policy-gated tool layer, event-driven architecture, an MCP framework with 4 custom tools, and 15 passing unit tests (FastAPI, SQLAlchemy, Celery, Redis).
- **Custom-Research** — a serverless RAG pipeline on AWS: ingests papers from arXiv, embeds them with 1024-dim Amazon Titan vectors, and serves semantic search + LLM chat over Aurora PostgreSQL/pgvector, all deployed via AWS CDK.
- **SEC-edgar** — a financial analytics platform mining SEC 10-K filings; built the MongoDB data pipeline, OpenAI-based filing summarization, and GitHub Pages deployment.
- **drone_exploration** — an autonomous exploration system combining Q-learning and SLAM, reaching 94.7% environment coverage at <1% collision rate, shipped as a public Docker image.
